Description

Ce projet implémente le jeu classique Tetris, avec une interface graphique intuitive et des contrôles faciles à utiliser. 
L'objectif est de créer une expérience de jeu fluide, tout en appliquant des principes de programmation structurée et graphique.

Fonctionnalités principales

- Interface graphique.

- Contrôles clavier pour déplacer et faire pivoter les pièces.

- Comptage des points basé sur les lignes complétées.

- Gestion des niveaux, avec une augmentation progressive de la difficulté.

- Sauvegarde et affichage du score maximal.

- Ajout du mode 1 contre 1.

- Ajout du Gamemode


Pourquoi utiliser la bibliothèque Raylib ?

La bibliothèque Raylib a été choisie pour les raisons suivantes :

- Simplicité d'utilisation : Raylib est adaptée aux débutants avec une documentation compléte.

- Performances optimisées : Raylib est parfaite pour des jeux 2D comme Tetris.

- Fonctionnalités graphiques puissantes : Raylib permet de dessiner facilement des formes, de gérer les entrées clavier, et de gérer l'affichage graphique sans nécessiter de configurations complexes.
